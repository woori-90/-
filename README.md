# ☕ 브릿지 커피 디지털 메뉴판

손님이 테이블의 QR코드를 찍으면 **휴대폰으로 보는 디지털 메뉴판**입니다.
파일 하나(`index.html`)로 되어 있고, 인터넷 연결이나 설치 없이 열립니다.

## 화면 구성

- **맨 위**: 가게 이름, 한 줄 소개, 위치
- **카테고리 버튼**: 전체 / 커피 / 논커피 / 디저트 (누르면 해당 메뉴만 보임, 스크롤해도 위에 고정)
- **메뉴 카드**: 그림, 이름, 설명, 가격 (15개)
- **사장님 추천 표시**: 추천 메뉴에 이름표가 붙고 카드가 살짝 강조됨
- **오늘 품절 표시**: 품절 메뉴는 흐려지고 "오늘 품절" 도장이 찍힘
- **맨 아래**: 영업시간, 전화번호, 주차·좌석·인스타 안내
- **맨 위로 버튼**: 길게 내려갔을 때 한 번에 올라가기
- **디자인**: 칠판 스타일 (짙은 초록 칠판 배경, 분필로 그린 듯한 선과 글씨)
- **화면 대응**: 휴대폰 세로(390px 기준)에 맞춰 만들었고, 가로로 눕히면 메뉴가 2줄로 보임

## 열어보는 방법

1. 이 폴더의 `index.html`을 두 번 클릭하면 브라우저에서 열립니다.
2. 고친 뒤에는 저장(Ctrl+S)하고 브라우저에서 새로고침(F5)을 하세요.

## 자주 하는 수정

모두 `index.html` **맨 위쪽**에 한국어 주석과 함께 모여 있습니다.

| 하고 싶은 일 | 고칠 곳 |
| --- | --- |
| 오늘 품절 켜기/끄기 | `const 품절메뉴 = ["스콘"];` 처럼 메뉴 이름을 넣거나 빼기 |
| 사장님 추천 바꾸기 | `const 추천메뉴 = ["아인슈페너", "흑임자 라떼"];` 에서 이름 넣거나 빼기 |
| 가격 바꾸기 | 메뉴 줄 끝의 `가격: 4500` 숫자만 고치기 |
| 메뉴 추가 | 비슷한 메뉴 줄을 통째로 복사해서 붙이고 내용 바꾸기 |
| 메뉴 삭제 | 그 메뉴 줄 전체 지우기 (또는 줄 앞에 `//` 붙여 잠시 끄기) |

주의할 점:
- 메뉴 이름은 큰따옴표(`" "`) 안에 넣고, 줄 끝에는 쉼표(`,`)를 붙입니다. 맨 마지막 줄만 쉼표가 없습니다.
- 품절·추천 목록의 이름은 메뉴 이름과 **똑같이** 적어야 합니다. 틀리면 화면 맨 위에 빨간 안내가 뜹니다.
- 화면이 비어 보이면 방금 고친 줄의 쉼표나 따옴표가 빠졌는지 확인하세요. (Ctrl+Z로 되돌릴 수 있습니다)

가게 이름, 영업시간, 전화번호는 `index.html` 중간의 HTML 부분(`<header>`, `<footer>`)에 있습니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 메뉴판 전체 (HTML, CSS, JavaScript가 한 파일에 들어 있음) |
| `CLAUDE.md` | 이 프로젝트를 만들 때 지킨 작업 규칙 |
| `자료/기획시트.png` | 가게 정보와 메뉴를 정리한 기획시트 |

## 만든 규칙

- 화면에 보이는 글자는 모두 한국어
- 글꼴은 고운 돋움을 먼저 쓰고, 없으면 맑은 고딕
- 리액트 같은 복잡한 도구는 쓰지 않고 `index.html` 하나로만 구성
- 직접 고칠 곳에는 한국어 주석으로 안내
